# Full Stack Web App Template

This is a template structure for a modern full-stack web application featuring a React frontend and Node.js backend.

## Project Structure

### `/frontend`
This directory contains the React application.
- `public/`: Static assets like index.html, images, etc.
- `src/`: Source code for the React app.
  - `components/`: Reusable React components.
  - `pages/`: React components representing entire pages/views.
- `package.json`: Configuration and dependencies for the frontend.
- `tsconfig.json`: TypeScript configuration for the frontend.

### `/backend`
This directory contains the Node.js/Express backend.
- `src/`: Source code for the Node.js server.
  - `controllers/`: Request handling logic.
  - `models/`: Database models and schemas.
  - `routes/`: API route definitions.
- `package.json`: Configuration and dependencies for the backend.
- `tsconfig.json`: TypeScript configuration for the backend.

## Getting Started

1. Navigate to `backend` and install dependencies, then start the server.
2. Navigate to `frontend` and install dependencies, then start the development server.
